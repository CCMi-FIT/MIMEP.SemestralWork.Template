# MIMEP.SemestralWork.Template
A LaTeX template for the semestral project of NI-MEP / ANI-MEP (Modelling of Enterprise Processes) at FIT CTU, winter semester 2026/27.

Author: Ing. Marek Skotnica 
License: MIT

## DEMO palettes for draw.io

The diagrams (CSD, PSD, OFD) are drawn in [draw.io](https://app.diagrams.net/) with a DEMO shape library. Import one with *File → Open Library From → URL*.

**Recommended** — the palettes the course labs use, so your diagrams match the lab materials:

- CSD — Sergey Dunaevskiy: `https://raw.githubusercontent.com/dunaevskiy/demo-drawio-palette/master/Organisation%20Construction%20Diagram/OrganisationConstructionDiagram.xml`
- PSD — Sergey Dunaevskiy: `https://raw.githubusercontent.com/dunaevskiy/demo-drawio-palette/master/Process%20Structure%20Diagram/ProcessStructureDiagram.xml`
- OFD — Jana Martínková: `https://raw.githubusercontent.com/jmartinkova/demo-ofd-drawio-palette/refs/heads/main/OFD.xml`

**Also available** — `DemoPalette.xml` in this repository, Marek Skotnica's palette for the CSD:

- `https://raw.githubusercontent.com/CCMi-FIT/MIMEP.SemestralWork.Template/master/DemoPalette.xml`

Pick one palette per diagram type and use it throughout the project. The palettes look visibly different, so mixing them in one document is confusing.
